## 1. Real CG01 Engine Evaluation (SL-36 & CE-11)

### 1.1 The P1-01 Problem in V17.7.1
In V17.7.1, tests for CG01 invoked lower-level helper functions (`build_sweep_stop_descriptor`, `resolve_stop_anchor`, `plan_structural_stop`, `calculate_risk_reward`) separately. This provided component coverage, but bypassed the actual production candidate evaluator: `evaluate_cg01_candidate()`.

### 1.2 Full Runtime Evaluation in V17.7.2
In V17.7.2, `test_sl_36` and `test_ce_11` execute `evaluate_cg01_candidate()` with complete canonical closed context bundles across 4H, 1H, 15M, and 1M timeframes, realistic quotes, and active `StopPlacementPolicy`:

```python
dec = evaluate_cg01_candidate(
    context=ctx,
    quote=quote_dict,
    config=cfg,
    now_ms=now_ms,
    stop_policy=policy
)
assert dec.candidate is not None
assert dec.candidate.stop_loss == dec.candidate.stop_placement.selected_sl
assert dec.candidate.stop_loss == dec.candidate.calculation.stop_loss
```

### 1.3 Distant Valid SL under Real CG01 Evaluation (CE-11)
When market swing lows are extended (> 4.0× ATR), `evaluate_cg01_candidate()`:
1. Resolves the genuine swing anchor.
2. Computes the outward-quantized structural stop.
3. Automatically downscales quantity via `calculate_risk_reward()`.
4. Successfully outputs an eligible candidate when the independent target yields a compliant Net R:R.

## 2. Real M1 Model Evaluation (SL-37..SL-40 & CE-12)

The 4 primary M1 scalp model families are now verified by executing their production evaluator functions directly on `ScalpM1ModelService`:

### 2.1 M1 Reversal (SL-37)
- **Evaluator:** `ScalpM1ModelService.evaluate_m1_reversal_candidate()`
- **Input:** Closed 1M bars with verified sweep extreme, cluster context, and canonical quote.
- **Verification:** Produces eligible candidate with `stop_loss` bound to sweep anchor minus dynamic buffer. Missing ATR halts execution cleanly.

### 2.2 M1 Continuation / Trend BOS (SL-38)

### 2.3 M1 FVG Continuation (SL-39)
- **Evaluator:** `ScalpM1ModelService.evaluate_m1_fvg_continuation_candidate()`
- **Input:** Closed 1M bars with confirmed Fair Value Gap formation and retest.

### 2.4 M1 Sweep Reclaim (SL-40 & CE-12)
- **Evaluator:** `ScalpM1ModelService.evaluate_m1_sweep_reclaim_candidate()`
- **Input:** Closed 1M bars with liquidity sweep and immediate reclaim bar closure.
- **Verification:** Anchor bound to sweep reclaim extreme. Verifies candidate stop loss matches calculator and stop placement decision with zero drift.

## 3. Strict Stop Loss Equality Invariant

For every candidate generated by CG01 or M1 models under `PAPER_STRUCTURAL`:
$$\text{candidate.stop\_loss} = \text{candidate.stop\_placement.selected\_sl} = \text{candidate.calculation.stop\_loss}$$

When subsequently passed to the orchestrator ARM boundary:
$$\text{armed\_order.stop\_loss} = \text{candidate.stop\_loss}$$

No downstream service may alter, re-widen, or drift the stop loss price.
