   - In [`backend/services/v17_9_0_1_baseline_oracle.py`](../../backend/services/v17_9_0_1_baseline_oracle.py) (`_build_historical_subprocess_harness_code`, lines `2219`–`2324`), the harness used `inspect.getsource(IndependentPreRefactorBaselineOracle)` to embed the current-tree `IndependentPreRefactorBaselineOracle` class into the isolated historical subprocess string (`python -c worker_code`), and then invoked `IndependentPreRefactorBaselineOracle.evaluate_baseline_dict(...)` / `evaluate_baseline_best_direction(...)`.
